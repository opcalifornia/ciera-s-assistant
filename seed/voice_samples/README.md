# Voice Samples

Paste 20-50 real emails you've written here (replies to bookings,
negotiations, declines) as individual `.txt` or `.md` files before Phase 1's
voice-consistency work starts. See `PLAN.md` Section 16 / open question 5.

These are never committed with real personal correspondence by default —
this directory is yours to fill in locally. If you want them version
controlled, add and commit them explicitly.
